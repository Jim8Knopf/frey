# Legacy Stack Archive

This folder contains the previous Frey implementation:

- Docker service roles
- Old playbooks
- Previous documentation
- Service-specific helper scripts
- Generated notes and implementation summaries

It is intentionally outside the active `roles/`, `playbooks/`, `docs/`, `scripts/`, and `templates/` directories.

Use it as reference material while rebuilding modules. Do not add it back to `roles_path` unless you explicitly want to redeploy legacy services.
